看出来了吗——优惠码基本就是节日名本身，力度在七折到七五折之间，有效期一到两周。 春节那次还额外发过限量的一至三折券（数量分别是 50、100、200 个），但那批券只能在它的内测客户端里用，且当天就被抢完了。

用法（官方原话）：在订阅购买页选好你要的套餐，在弹出页面下方或侧方的「优惠券」一栏填入折扣码，检查没有多余空格和错字，点「验证」按钮，看到正确显示减免金额后再下单付款。

三、它为什么这么便宜？答案是「日限 20%」加低倍率节点

「赔钱机场为什么这么便宜」是它最高频的搜索词之一。旧版评测常见的答案是"用甲骨文和 AWS 的廉价机器"，这只说对了成本的一半。真正让这个价格跑得通的，是两条写在它自己公告里的机制，而这两条恰恰是买之前必须算清楚的：

机制一：每天只能用掉总流量的 20%

官方公告《每天流量限制为总的20%》原文：

每天统一限制20%，当日总结算扣费超出限制可能会重置链接，需要重新访问官网复制导入。但是严重超额或者恶意分享一经发现仍有可能永久封号。

也就是说，买 1000G 不等于你能一口气用完——按 1 倍节点算，每天最多 200G。这条对机场的意义很大：它不必按"所有人同时把流量跑满"的峰值来备带宽，成本立刻降下来。

机制二：大量 0.1x 与 0.01x 的低倍率节点

日限是按结算扣费算的，不是按你实际传输的字节算的——于是低倍率节点就成了解锁日限的钥匙。官方自己给了算法：

比如你流量套餐有1000G，只是使用1倍节点，每天可用200G，相同理论 0.1倍节点就允许你一天跑实际流量2000G，如果 0.01倍节点就允许你一天跑实际流量20000G。

本站在后台节点状态页数了一遍，这些低倍率节点是真实存在的（详见下一节）：69 个节点里 30 个是 0.1 倍，5 个是 0.01 倍。

所以正确的用法是：日常上网随便选，大流量的下载、更新、备份一律切到 0.1 倍或 0.01 倍节点——官方甚至专门提醒「1倍节点不建议各位跑下载」。反过来，如果你一直挂在 1 倍节点上跑大流量，很容易撞上日限被重置订阅链接，然后以为是机场坏了。

⚠️ 官方也补了一句边界：「不要长时间巨额占用给服务器过大压力」，长时间霸占单条线路可能导致节点掉线甚至封号。低倍率节点是给你省钱的，不是给你当无限流量用的。

反直觉的发现：长周期一分钱折扣都没有

大多数机场的年付会给到七八折，赔钱机场完全没有。本站逐档切换周期实测：

  • 一瓶盖可乐 月付 ¥1.50
  • 一瓶盖可乐 年付 ¥18.00 ＝ 1.50 × 12
  • 一瓶盖可乐 三年付 ¥54.00 ＝ 1.50 × 36

严格线性，买三年和按月买，每 GB 一分不差。 这条结论很重要，因为它把"要不要押长周期"这个问题直接消掉了——既然长期没有价格优势，对一家带着封号争议的低价机场，就完全没有理由把钱押进去。买月付，用得舒服下个月再买。

另外三条计费规则容易踩（都出自官方公告）：

  • 不支持任何理由的退换或补差抵扣，下单前想清楚。
  • 换一个名称不同的套餐，会让旧套餐被覆盖消失且无法恢复。要升级档位，等旧的用完或到期再买。
  • 续费只延长周期、不重置流量；重置流量得单买「流量重置包」，而且只有当月流量消耗超过 80% 时才能买。这两件事是分开的，很多人买错。

想知道它到底快不快？自己测一遍最准

低价机场的速度会随时间和地区剧烈波动，任何评测里的测速数字都只代表作者当时那条网络。与其信别人的截图，不如把订阅贴进机场订阅节点在线测速自己跑一遍：它会逐个节点测存活、延迟、下载速度，还能一并检出 Netflix / ChatGPT / YouTube / Disney+ / Gemini / TikTok 的解锁情况和落地 IP 风险，最后生成一份可分享的报告。

⚠️ 在赔钱机场用测速工具，有一个专属注意事项：测速要真实下载数据，这些流量会计入你的套餐、也计入那条 20% 的日限。它 69 个节点全测一遍不是小数目，所以建议：

  • 选「每个地区 1 个」或「最快 3 个」这类抽测档位，别一上来就点「全部」；
  • 更省的做法是先挑几个 0.1x 节点测——同样测一遍，扣费只有十分之一。

六、跑路与封号争议：把三年前的旧账和现在的问题分开

搜「赔钱机场跑路」的人会看到不少吓人的说法。本站这次把能查的都查了一遍，结论需要分成两件独立的事来说。

第一件：跑路名单上确实有它，但那是 2023 年的记录

GitHub 上的跑路监测项目 limbopro/Paolujichang，正文名单里有这么一行：

赔钱机场 ｜ 机场 ｜ 已跑路/高风险 ｜ [参阅] ｜ 06.18.2023

但这条记录现在已经无法查证——它唯一的举证链接指向 Telegram 频道 @airportbbq 的一条消息，而该频道已被 Telegram 官方以违反服务条款为由封禁，页面只剩一句「This channel can't be displayed」。

所以诚实的说法是：「赔钱机场」这个招牌在 2023 年 6 月被记过一次跑路，但事件细节已随频道消失而不可考，本站无法确认那次事件与现在这家是否为同一批运营者。 早期评测里流传的「五人合伙、掌握数据库的技术合伙人踢出其余四人」那套说法，原始出处同样指向那批已消失的消息，本站找不到任何可核验的一手证据，因此这次更新不再把它作为事实转述。

同时也要更正本站上一版的一处措辞：上一版写的是「多个独立跑路名单都收录或讨论过」，本次逐个核查后发现，能查到的原始收录只有 limbopro 这一处（其余多为第三方博客的相互转载），本站把说法收窄到与证据相符。

第二件：现在真正该关心的是「乱封号」，而且它还开着

比三年前的旧账更值得看的，是这条 2026-05-21 提交、至今仍未关闭的预警：

[机场跑路/预警] 赔钱机场乱封号 —— 机场状态：服务可用｜已使用时长：几个月｜近期续费：1 年 「服务质量差，网络延迟波动大」「便宜是真的很便宜」「乱风控触发封号，就这么便宜的东西，都是直接拿来当副机场使用的，也是直接推荐同事购买，怎么可能拿去分享使用……」

九条评论里的反馈是两极的，两边都值得看：

  • 有用户说自己「就我自己登，前几天突然全部节点 error，今天一看节点变成"使用设备过多"」，推测是因为平时用 PC、前几天手机也用了一下；
  • 另一位用户提出一个很关键的猜想：是不是同一个设备的客户端对机场的多个节点做了批量测速？
  • 但也有用户说「我用了一年多了没出现这种情况，而且还挺稳定的」，还有人说自己分享给朋友、合计五台设备也没被封。

把这些和它自己的条款对起来看，图景就清楚了——官方公告里明写着：

  1. 官网主页在线设备显示并不完全准确，显示 0~5 左右均为正常现象。
  2. 不要使用过多设备同时连接或进行可能会导致设备数量异常增多的情况，如有设备数量几十上百的情况，可能会触发链接重置需要重新复制链接重新导入，严重时可能会导致封号。

也就是说，它有一套触发条件不透明、且它自己承认统计不准的设备数风控。这不是"随机封号"，但对用户来说效果差不多：你不知道哪个动作会踩线。结合评论区那个猜想，一条低成本的自保建议是——别在客户端里对全部节点反复做批量延迟测试，那会在短时间内产生大量并发连接。

本站的结论：它没有跑路，服务是活的（69 个节点在线 63 个、TG 群 2.8 万人近 500 在线、频道 8 月还在更新）。但这套不透明的风控加上"任何理由都不退款"的条款，构成了实打实的信用风险——你可能在任意时点失去一个还没用完的账号，且拿不回钱。这也是本站不把它放进首页机场筛选器/推荐位的原因。想系统性地学会评估这类风险，见机场防骗甄别指南。

七、下载、Clash 配置与几条排障要点

客户端在哪下载

后台「Tutorials」页覆盖 Android / iOS / Windows / macOS / OpenWrt 五个平台，并且直接在自己站上放了安装包（不用去 GitHub 挤）：

  • Windows / macOS：Clash Verge Rev（站内提供 2.3.1 安装包）或 v2rayN
  • Android：Clash Meta for Android、V2RayNG
  • iOS：Shadowrocket（小火箭）
  • Linux / 路由器：官方明说「不提供完整教程，请自行测试」

⚠️ 关于「赔钱机场 GitHub」这个搜索词：它自己没有 GitHub 仓库，你搜到的 GitHub 链接是两类——一类是客户端项目本身（clash-verge-rev、2dust/v2rayN），一类是上一节那个跑路监测仓库。官方常见问题里对 GitHub 只提了一句：「github 下载速度缓慢属正常现象」，建议有能连的设备就先下好再传过去。

Clash 配置：只要一条订阅链接，不用手写配置

导入方式就是把官网的订阅链接贴进客户端更新订阅，不需要自己写 YAML。但有一个版本坑必须避开：

Clash for Windows 已经不再维护，且不支持 Hysteria2 这类协议，请换用 Clash Verge。

它的 69 个节点里有 14 个是 Hysteria2，用老版 Clash for Windows 会直接看不到或连不上这批节点——这是最常见的"以为机场缩水了"的误会。

几条官方给的排障要点

  • 报错含 proxy、切换配置关键词 → 客户端版本太老，按官网文档更新。
  • 报错含 get……eof → 回官网重新复制订阅链接再导入，导入时关掉其他 VPN，可以先把订阅链接在浏览器里打开一次再回客户端导入。
  • 大量节点用不了 → 先更新订阅；仍不行就在个人中心最下方重置订阅链接后重新导入。⚠️ 它在 2026 年做过一次强制更换订阅链接，官方给的应急改法是把旧链接里 v1/client/subscribe?token=xxxx 那段改成 v1/pq/xxxx。
  • 电脑开了系统代理仍不通 → 换节点；无效则关掉系统代理，安装 service mode（服务模式）后开启 TUN 模式。
  • 付款后订单仍显示待支付 → 耐心等 1~5 分钟，绝对不要取消订单或重新下单，否则官方明说无法到账且无法恢复。

八、优缺点与适合谁

优点

  • 价格确实是地板价：100G/月 ¥1.5、20000G/月 ¥39.99，每 GB 低到 ¥0.002，横向比是全行业最低那一档。
  • 有真正可用的低倍率节点：0.1x 有 30 个、0.01x 有 5 个，跑下载时等于把流量放大十倍百倍。
  • 节点在线率不差：69 个里 63 个在线，协议是较新的 VLESS 与 Hysteria2。
  • 优惠码有明确规律：按节日发七折到七五折，蹲得到。
  • 设备数给得宽松：最低档就给 10 台，最高档 300 台。

缺点

  • 所有中文官网域名都已被墙，只剩英文域一支能直连，且它换域名很频繁。
  • 有一条至今未关闭的「乱封号」预警，风控触发条件不透明，官方自己也承认设备统计不准。
  • 任何理由都不退款，换套餐还会覆盖旧套餐。
  • 长周期零折扣，价格严格线性，押长期毫无收益。
  • 日限 20% 让"标称流量"和"能用的流量"是两回事。
  • 全直连、无国内中转，晚高峰体验看运气；官方还有节点直接标着「避免晚高峰使用」。
  • 不支持 UDP、IPv6、冷门地区节点，限制非 443 端口，TikTok 明确受运营商检测影响。

适合：已经有主力机场、想再花几块钱备一条便宜后路的人；下载/离线需求大、愿意专门去挑 0.1x / 0.01x 节点的人；能接受"随时可能因风控丢号"这个前提的人。

不适合：把它当唯一主力的人；想一次买长期图省事的人（长周期零折扣，纯粹亏时间价值）；需要 UDP、游戏加速、TikTok 稳定养号的人；不能接受不退款条款的人。

想更稳一点，几个方向：

  • 更极限的备用号 → 三毛机场：年付 3 元起，同样是备胎定位，但计费规则更简单（没有日限，只有峰谷倍率）。
  • 要一条真能当主力的平价线 → 飞鸟机场、大哥云，十几二十块换来的是"不用担心账号哪天没了"。
  • 就是冲大流量便宜来的 → 大流量机场推荐，横向比完再下手。

九、常见问题（FAQ）

官网与入口

赔钱机场官网入口是哪个？为啥进不去了？

后台公告列了六个域名，但本站 2026-09-03 不挂代理实测发现：所有中文域名都已被墙（赔钱机场.com、赔钱机场.site、www.赔钱机场.site、dash.赔钱机场.site、dash.赔钱.com，其中前两个 DNS 已被污染），只有英文域 pqjc.site 系列还能国内直连。进不去通常不是它关站了，是你手上那个是中文域，换成 dash.pqjc.site 即可。

打开是一个「Verify you are human」的页面，正常吗？

正常，那是 Cloudflare 的人机验证，一般几秒自动通过后进入面板。所有域名都打不开时，去官方 TG 频道 t.me/peiqianjichangpd 拿最新地址。

价格与优惠

赔钱机场有优惠码吗？优惠卷怎么领？

有，按节日在官方 TG 频道发，力度七折到七五折，码基本就是节日名：2026 年依次是「新年快乐」「劳动节快乐」「端午」「七夕」。用法是购买页选好套餐后，在弹出页面下方或侧方的「优惠券」栏填码并点「验证」。截至 2026-09-03 没有生效中的码（七夕轮 8 月 25 日结束），蹲下一个节日即可。

赔钱机场买长期套餐划算吗？

不划算，因为根本没有长期折扣。实测一瓶盖可乐月付 ¥1.50、年付 ¥18.00、三年付 ¥54.00，严格等于单价乘月数。既然买三年和按月买单价一样，就没有理由为一家有封号争议的低价机场押长周期。

机制与用法

赔钱机场为什么这么便宜？

核心是两条它自己写在公告里的机制：每天只能用掉总流量的 20%（不必按峰值备货），以及大量低倍率节点（69 个节点里 30 个 0.1x、5 个 0.01x，0.1x 节点下载 10G 只扣 1G）。再加上全直连、无国内中转，价格就压到了每 GB 几厘。

每天 20% 的限制会怎样？

按结算扣费算，当日超出可能会重置你的订阅链接（要重新去官网复制导入），严重超额或恶意分享则可能永久封号。解法是把大流量操作切到 0.1x 或 0.01x 节点——官方自己算过，1000G 套餐在 0.1x 节点上一天可跑 2000G 实际流量。

赔钱机场客户端在哪下载？Clash 怎么配置？

后台「Tutorials」页有五平台教程与安装包（Windows 站内直接给 Clash Verge Rev 2.3.1）。导入只需贴订阅链接，不用手写配置。⚠️ 老版 Clash for Windows 不支持 Hysteria2，会看不到那 14 个 Hy2 节点，必须换 Clash Verge。

赔钱机场怎么测速？

把订阅链接贴进在线测速工具逐个节点跑存活、延迟、下载速度和流媒体解锁即可。注意测速会真实消耗流量并计入 20% 日限，建议选「每个地区 1 个」这类抽测档位，或专挑 0.1x 节点测。

安全与风险

赔钱机场跑路了吗？靠谱吗？

截至 2026-09-03 在正常运营：69 个节点在线 63 个、TG 群 2.8 万成员近 500 在线、频道最近更新 2026-08-19。跑路名单里确实收录过「赔钱机场｜已跑路」，但那是 2023-06-18 的记录，且唯一举证链接所在的 TG 频道已被官方封禁、内容无法查证，本站无法确认与现在这家是否同一批运营者。

赔钱机场安全吗？会不会乱封号？

跑路名单里有一条 2026-05-21 提交、至今未关闭的「乱封号」预警，有用户称仅 PC 加手机两端使用就被判「使用设备过多」；但同一条评论区也有用户用了一年多没出问题。它的官方条款印证了这套风控存在：明写"不要使用过多设备同时连接"、严重时封号，同时承认在线设备统计"并不完全准确"。低成本自保：别在客户端里反复对全部节点做批量延迟测试，别把订阅分享出去。

「赔钱机场 GitHub」搜到的是什么？

它自己没有 GitHub 仓库。你搜到的要么是客户端项目（clash-verge-rev、2dust/v2rayN），要么是跑路监测仓库 limbopro/Paolujichang。官方文档里唯一提到 GitHub 的地方是"下载速度缓慢属正常现象"。
