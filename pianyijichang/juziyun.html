桔子云跑路了吗？——没有，是墙在升级

近期搜「桔子云跑路/跑路了」的人变多，直接说结论：桔子云没有跑路，而是遇到了全行业性的防火墙升级。证据就是官方发布的紧急公告，要点如下（也是你现在该做的操作）：

  • 官方明确表态：「防火墙升级期间，全国多地机房受影响，网络波动较大」「我们仍有可用线路，请勿到处乱买」——主动发公告、给操作指引、劝用户别流失，这是跑路机场不可能有的行为（对照：真跑路的 Sockboom 是静默失联、零通知）
  • 电脑/安卓/Mac：下载官网最新 Clash 客户端，逐一测延迟找可用线路
  • iPhone（小火箭）：一键导入或手动复制订阅，优先使用 anytls / Hysteria 节点——看不到这两类节点说明你的 Shadowrocket 版本太旧，先更新
  • 苹果节点全部不可用的重置流程：断开连接 → 「数据」栏删除所有节点 → 彻底退出小火箭 → Safari 打开官网点「一键订阅」重新导入；并建议开启「打开时更新」、关闭「温和策略机制」
  • 鸿蒙用户：最新鸿蒙系统可能拦截 APK 安装，需自行降级或换设备（这是鸿蒙收紧侧载的系统性问题，不是桔子云独有）
  • 订阅更新失败/导入失败：检查系统时间是否为北京时间，或切到数据流量再试

一个重要的技术信号：公告里「优先使用 anytls / Hysteria 节点」说明桔子云的协议栈已经升级——anytls 和 Hysteria2 正是当前抗封锁能力最强的新协议梯队。墙升级期它有新协议节点可切，这是「还能继续用」的底气，也是很多还停留在「SSR/V2ray 机场」印象里的旧评测没写到的。

单价怎么看

  1. 入门版是「三重受限」档，不建议买：¥0.20/GB 全场最贵单价＋60M 限速＋只能用最低档节点——三样全占。它的存在更像价格锚点，真把它当主力体验会大打折扣
  2. 旗舰版是甜点位：¥0.10/GB＋不限速＋全节点（含 IPLC 专线）三样全解锁，比标准版只多 ¥20 却跨过了「不限速」和「全节点」两道门槛——预算够得着 ¥60 的，直接旗舰，中间两档都是过渡
  3. 旗舰大流量的 ¥0.083/GB 只对真大户有意义：月耗不到 600G 买它就是浪费，流量到期清零（见下）
  4. 两条购买规则必看（官方明示）：① 流量一次性到账、到期清零——按周期内真实用量买，囤不住；② 大额套餐可能因支付接口限制无法直接付款，先到【我的钱包】分次充值再购买；已有套餐换档走首页【升级套餐】按钮，别直接买新的

节点与解锁

  • 节点：近 50 个付费节点，覆盖香港、台湾、日本、新加坡、美国等主流地区；CN2/BGP 隧道中转为主，高档含 IPLC 专线（如深圳-香港 IPLC）
  • 协议：SSR、V2ray（vmess），新增 anytls / Hysteria2（墙升级期的主力抗封锁协议）
  • 流媒体：大部分节点支持解锁当地 Netflix、Disney+（Netflix 偶发 IP 封锁导致短时失效，行业通病）；第三方记录其 IPLC 节点白天晚上看 YouTube 4K 流畅
  • 审计：有——国内中转线路的常规操作，屏蔽极端政治、金融诈骗、BT 下载及 360 系软件，下载党绕行
  • 客户端：全平台（Windows/macOS/Android/iOS/Linux），官网有最新 Clash 下载；iOS 用小火箭

优缺点

优点

  • 速鹰系老牌站群背书，2020 年至今运营、公益机场转正的历史
  • 协议栈跟进快：anytls/Hysteria2 已上线，墙升级期有牌可打
  • 官方应对透明：波动期主动发详细公告和操作指引，不玩失踪
  • 旗舰档 ¥0.10/GB 不限速＋IPLC，价格在中转＋专线混合档里有竞争力
  • 注册送 10GB，零成本试线

缺点

  • 套餐三重分层严格，低档体验缩水明显（入门版不推荐）
  • 流量到期清零＋大额支付要分次充值，购买规则有学习成本
  • 有审计、屏蔽 BT；中转为主，别拿纯专线标准要求低档
  • 速鹰系通病：主域常被墙，官方要靠三十多个备用域名轮着用（见上文清单），认域名成本高、也给仿站留了空子

适合谁 / 不适合谁

  • ✅ 适合：预算 ¥60 档、要不限速＋IPLC 全节点的日常主力用户（旗舰版）
  • ✅ 适合：墙升级期需要 anytls/Hysteria2 新协议节点应急的用户
  • ✅ 适合：信任速鹰系老团队、想要「大站群＋老分站」稳定感的人
  • ❌ 不适合：预算 ¥20 档的轻度用户——入门版三重受限，同价位不如 飞鸟机场（¥15 不限速）或 魔戒机场 的点卡
  • ❌ 不适合：BT 下载党；已在用速鹰/优云/极客云、想找灾备的人（同系不互备，请选 WgetCloud 这类其他团队的机场）

常见问题（FAQ）

跑路与故障排查

桔子云跑路了吗？还能用吗？

没有跑路。近期波动源于防火墙升级影响多地机房，官方已发布应对公告并持续维护，有可用线路（优先 anytls/Hysteria 节点）。本文每月核实更新。

桔子云节点全部超时/连不上怎么办？

按官方公告操作：更新客户端到最新版 → 优先选 anytls/Hysteria 节点 → 小火箭用户走「删节点-退出-重新一键订阅」重置流程 → 检查系统时间为北京时间或切数据流量。

桔子云支持鸿蒙吗？

最新鸿蒙系统可能拦截 APK 侧载（系统性问题），官方建议自行搜索降级方案或更换设备；旧版鸿蒙可正常安装安卓客户端。

谱系与套餐

桔子云是哪家的？

速鹰系（极客云系）站群的老牌分站，2020 年成立，曾做免费公益机场后转为收费，同系还有极客云、优云、速云梯、尔湾云等。

桔子云哪个套餐划算？

旗舰版 ¥59.99/600G：¥0.10/GB＋不限速＋全节点是甜点位；入门版三重受限（限速 60M＋低档节点＋最贵单价）不建议。流量到期清零，按真实用量买。

桔子云怎么免费试用？

注册即送 10GB 流量，可测试对应档位节点后再决定付费。

桔子云大额套餐付不了款怎么办？

官方说明为支付接口限制：先到【我的钱包】分次充值，再用余额购买；换套餐走首页【升级套餐】按钮。
