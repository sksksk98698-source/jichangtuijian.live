还能用Clash、小火箭吗？旧订阅不能原样搬过来

当前仍有第三方订阅教程，不能说已经全部封死。 但 7 月的官方说明明确推荐 FlClash、Shadowrocket，并写明不再支持 V2rayNG、Surfboard。如果只愿意使用某款特定软件，这个限制比折扣更值得先确认。

  • FlClash：按后台最新教程导入订阅，在配置页添加 URL、选择节点并开启代理；部分节点失效时手动同步订阅。不要把其他机场的旧配置步骤直接套过来。
  • Shadowrocket（小火箭）：官方教程强调，只复制订阅或扫二维码不够，还必须按图文步骤加载配置模块。老用户要按新教程替换旧配置；换手机后也要重新完成配置。
  • 官方客户端：目前优先使用导航提供的新版。公告要求升级到 2.0.18 或以上，旧版本可能识别不了后来切换的 Trojan 节点；官网已有 2.0.20 安装包，无须特意找旧版。

官方还明确说，未来如果维护第三方订阅的条件继续恶化，可能彻底关闭第三方订阅支持。这是购买兼容性风险，不等于已经宣布关站；长期只用小火箭或 Clash 的人，别把它永久支持第三方当作买多年套餐的前提。

因此，本文不把它继续归成“全 IEPL 专线机场”。Trojan 是协议名称，也不能单独证明线路质量。套餐卡片上的“最高1000Mbps、流媒体深度解锁”属于官方标称，本次账号没有有效订阅、节点列表为空，没有证据把这些宣传写成实际测速或解锁保证。

OK Cloud怎么样，跑路了吗？还有哪些使用限制

后台最早在售套餐可追溯到 2022 年 8 月，9 月仍更新客户端下载文档和常见问题；官方主站、备用面板与优惠券核价都在工作。结合公开跑路名单及相关检索，本次未见足以认定它已经停止运营的证据。

但“还在运营”不等于“节点始终稳定”。官方自己多次发布超时、协议迁移和第三方配置调整说明；这些变化与其所述的网络环境压力有关，不能只凭个别连接失败就认定跑路，也不能拿外部环境解释来替它保证使用效果。AegisClient 商店评论也存在卡顿、客服问题的反馈，不过评论不足以确定每位用户所连服务和故障原因，不能直接当作 OK Cloud 全部节点的测评。

付款前还要注意这几项官方规则：

  • 台湾节点是 2 倍率，其他地区标为 1 倍率。按官方说明，台湾实际用了 10G，会扣约 20G 额度；套餐流量不等于所有地区都能用到同样多。
  • 仅针对中国大陆出境访问优化，知识库明确写不支持海外用户和回国。客户端里出现“国际线路”选项，不等于它承诺提供回国加速服务。
  • 不是游戏加速器，官方不保证任何游戏加速效果；不要照冒名页的“游戏专线”宣传购买。
  • 设备数量有限制，周期套餐是 5、10、20 台分档，不限时包均为 5 台；“不限本人设备数”是旧资料。
  • 七天免费试用未核实为当前有效：现有九档购买列表没有试用项，本次账号也没有可用试用服务。如果你是冲着旧介绍中的试用而来，先向客服确认，别先付款再等赠送。

哪些人适合，哪些人更该换个选择

已经熟悉 OK Cloud、能接受官方客户端或指定第三方配置的人，可以按实际月用量选档。首次使用建议先选月付，确认自己的网络和设备下能用，再决定是否续费；只看中“十元出头”却不想一次付一年的人，要注意入门档的付款门槛。

如果是为了低成本备用，或希望客户端兼容方式更自由，可以先看机场推荐榜中预算有限的比较，再对照以下需求：

  • 主要是降低备用成本：飞鸟云有低价周期档与流量包，但需要自行配置和维护订阅，不能把低价等同于稳定保证。
  • 想比较常规月付与长期价格差别：大哥云评测列了不同周期的单价，可以与 OK Cloud 的“长周期直接乘月数”一起算总投入，而不是只比优惠券折数。

常见问题

OK Cloud怎么样，跑路了吗？

截至2026年9月24日，OK Cloud后台可以登录、套餐仍在售，9月还有客户端和公告更新，未见当前停止运营证据。但本次没有有效订阅，未实测节点速度与解锁。旧域打不开不能单独证明跑路；首次购买宜先选短周期，不能只凭官网能开就买多年。

OK Cloud官网是哪个？

国内优先使用web1.okokokokcloud.com、web2.okokokokcloud.com或web3.okokokokcloud.com；okyun01.com是官方地址与下载导航。okokcloud.xyz等旧域仍有面板，但国内部分网络打不开。okcloud.homes的注册按钮指向浪网WaveNet，不是本文这家的注册入口。

okcloud优惠券现在几折？

本次验证okcloud为85折，150G月付30元减至25.50元，100G年付144元减至122.40元，不限时100G从400元减至340元。okyun01.com九折仍有效，但优惠较少；okokcloud和7zheyouhui均返回无效，不能继续按旧七折宣传计算。

OK Cloud下载在哪里？iPhone叫什么名字？

Windows、Mac和安卓从官方导航okyun01.com或后台使用文档下载；本次提供2.0.20版。iPhone和iPad使用AegisClient，需要非中国大陆区App Store，站点识别码是okcloud。商店中的OK Cloud云盘浏览器不是这家的VPN客户端。

OK Cloud还能用Clash和小火箭吗？

当前仍提供第三方订阅教程，明确推荐FlClash和Shadowrocket。小火箭必须按最新教程添加配置模块，只复制订阅或扫码不够；V2rayNG和Surfboard已不再支持。官方也声明必要时可能关闭第三方订阅，因此不能把永久兼容当成购买前提。

OK Cloud有月付、免费试用和退款吗？

100G入门档只有年付，真正按月购买从150G的30元起，85折后25.50元。当前九档购买列表没有试用档，本次账号也未获得可用试用服务，不能保证旧评测里的七天免费试用仍有效。套餐页明确写不支持退款。
