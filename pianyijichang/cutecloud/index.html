客户端怎么选、规则怎么配(2026-07-08 官方公告口径)

搜「cutecloud app / cutecloud 安卓 下载 / cutecloud 如何配置规则」的看这节,官方 2026-07-08 公告把兼容性说得很清楚——它正在把用户往自家客户端迁移:

  • Windows / macOS / Android:用官网下载的 CuteCloud 0.8.93 Build 2 或 1.6.4;新版本优化了首次登录、订阅下发和更新速度
  • ⚠️ 旧客户端在被淘汰:官方明说「后续将无法继续兼容 Clash for Windows、旧版 Clash,以及大部分不支持 Mihomo / Clash Meta 新特性的代理软件」——还在用 CFW 的,别指望它长期能用
  • iOS:优先 Clash Mi 或 DigiLink(均免费,需外区 Apple 账户下载,建议自己注册一个,别用共享账户登录 iCloud)
    • Clash Mi:「我的配置」里点登录,输入 vpn 或 cutecloud,登录自己账号即可下发配置;如果核心设置里的「覆写」开关默认开着,关掉并重启——搜「cutecloud 如何配置规则」的十有八九是栽在这个覆写开关上
    • DigiLink:验证信息填 ccc,登录自己账户即可使用
  • Shadowrocket 小火箭:要从官网导入完整配置才能用,而且测延迟不准,以实际使用为准;其他第三方客户端官方均不保证稳定支持

一句话:入坑就直接用它自家客户端或 Clash Mi,别拿老客户端硬凑——官方已经把路线图挑明了。

「共享 Apple ID」赠品:好用,但会用才安全

套餐附带「少量共享账户使用权」(如 Apple ID)——这是给你下载外区 App(比如 iOS 代理客户端)用的。安全边界必须说清:共享 Apple ID 只在 App Store 登录、只用来下载应用;绝对不要登进「设置 → iCloud」——共享账户一旦被开锁定,你的设备可能被远程锁死变砖。这不是最萌云一家的问题,是所有共享 Apple ID 的通用铁律。官方也提示下载用的外区账户「建议自己注册,安全性和稳定性更好」——说明它自己也知道共享账户只是过渡方案。

常见问题(FAQ)

没有。limbo 跑路监测库以「cutecloud」「最萌」检索为 0 条记录,连预警都没有;官网与备用入口 2026-07-24 实测均在线,2026-07-08 还发了客户端更新公告。「打不开」多半是域名被墙(连上节点再开)、官网防爬验证,或者点进了蹭名假站。

真官网是 cutecloud.net(2023-01 注册,备用入口 1.cutecloud.net)。cutecloud.org、cutecloud.pro、cutecloud.vip、cute-cloud.com 全是 2025 年 12 月之后才注册的蹭名站,RDAP 注册记录摆在那,别信它们的「新版官网」话术。
