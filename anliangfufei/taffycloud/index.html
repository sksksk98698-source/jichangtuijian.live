三个名字一家店：Taffy Cloud、永雏塔菲的魔法卷轴、原 MoFast

搜索结果里这几个名字满天飞，很容易以为是好几家。先把关系理清楚，这是理解后面所有内容的前提。

Taffy Cloud = 永雏塔菲的魔法卷轴 = 魔法卷轴机场，同一家。 登录 tf520.top 的面板，页面顶部挂着的标题原样就是「永雏塔菲的魔法卷轴」，公告栏叫「听 Taffy 说」，页脚版本号写着「@永雏塔菲」；而它的英文品牌名、社交账号、第三方导航站收录用的都是 Taffy Cloud，官方帮助文档站的标题则是《魔法卷轴使用说明书》。不是母公司和子品牌，也不是新旧两代产品，你在不同站点看到这几个名字被分别评测，是同一家被写了好几遍。

「原 MoFast」这个说法则要打个折扣。 到处写着「TaffyCloud（原 MoFast）」，那个「原」字会让人以为是同一批人换了块招牌，实际不是。

2023 年 6 月那次转让，域名注册时间刚好佐证

MoFast 魔法云是一家 2021 年前后就在运营的按量付费机场，主打的就是先用后付、用多少扣多少。2023 年 6 月 16 日，MoFast 官网挂出转让公告：网站已经出售，数据全部移交给买家 Taffy Cloud，并承诺注册过的用户数据全部保留、老用户不需要重新注册。

这个时间点有一条独立证据能对上：taffy.cloud 这个域名的注册时间是 2023 年 6 月 15 日，比转让公告早整整一天。 买方提前一天把新品牌的域名注册好，隔天卖方挂出公告——两条来源互不相干，时间线严丝合缝。

所以准确的说法是：这是一次资产转让，Taffy Cloud 是买方。 这和「改名」对用户的意义完全不同：改名的还是同一批人，转让则是新老板接手了域名和用户名单，运维能力、跑路倾向、服务态度都得重新观察，MoFast 时期攒的口碑不能直接算在它头上。

承诺兑现得怎么样？有评测站记录了自己的亲身经历：迁移初期确实能用原账号登进 Taffy Cloud、余额也还在，但一天之后再登录，系统提示账户不存在，原余额消失了。这是单一来源的说法，本站无法独立复现（那批账号早已过期），只能当方向性参考——但它至少说明「数据全部保留」当年执行得并不干净。

顺带一提，「魔法」这两个字倒是从魔法云一路留到了魔法卷轴。

顺便纠正一条：它不是 2021 年开业的

好几个页面写着「开业可追溯到 2021 年」。那是前身的年份被算到了接手方头上。 2021 年开业的是 MoFast；Taffy Cloud 这块牌子最早的可查证据是域名注册于 2023 年 6 月 15 日，面板里的套餐记录建于 2024 年 1 月 30 日，都撑不到 2021 年。

（另外别拿现在这个 mofast.cloud 当 2021 年的证据——它的注册时间是 2025 年 8 月 20 日、注册商也和这家其他域名不同，是老域名掉签后被别人重新注册的常见情况。）

「已暂停注册」是假的：那句话只对没带邀请码的人显示

这是本文最重要的一条，也是把之前所有中文评测——包括本站上一版——集体带沟里的一个坑。

先说现象

不带邀请码打开它的注册页，你会看到这么一张卡片：

注册新账户 本站目前已暂停注册，只维护现有用户 请前往合作友站：xuelian.pro 按使用分钟计费 无限流量 返回登录

页面上一个输入框都不渲染，除了「返回登录」按钮和那个友站链接，没有任何可填的东西。任何人看到这一屏，都会得出「这家关站不接客了」的结论——满网一年多来的「TaffyCloud 关闭注册」「已停止新用户注册」，源头基本都在这里。

再说真相：这段提示的显示条件

本站这次把前端 chunk 拉下来看了渲染逻辑。那张卡片的显示条件是这样写的：

is_invite_force && !user_affcode || is_stop_register
  ? 渲染「本站目前已暂停注册」卡片
  : 渲染正常注册表单

拆开看就是满足任一条件才显示：

  1. 强制邀请码开着，而当前 URL 里没有邀请码；或者
  2. 注册停用开关被打开

同一天拉官方 guest 配置接口，两个值分别是 is_invite_force = 1、is_stop_register = 0。也就是说，触发这张卡片的是第一个条件——「没带邀请码」，而不是「注册被停用」。

提交注册时后端还会再校验一次，源码里那句是：

if (is_invite_force == 1 && !user_affcode)
    return warning("需要邀请码才可以注册");

注册功能完好，只是没有邀请码的人连表单都看不见。

为什么这个坑这么好踩

因为它的措辞选得很有误导性。同样是拦住无码访客，正常的做法是显示「本站需要邀请码才能注册」；而它显示的是「本站目前已暂停注册，只维护现有用户」，还顺手把人引去了另一家。这句话在字面上就是错的——站方没有暂停注册，它只是不接待没有邀请码的人。

至于引导去的那个 xuelian.pro：本站没有测过这家，不作任何评价，也不推荐。这里只是如实转述页面上的引导内容——页面标注它「按使用分钟计费、无限流量」，那是站方的说法。看到这类「友站」引导，请当成一次新的尽调对象，而不是被背书过的替代品。

这件事的方法论教训

本站在这篇文章上翻过两次车，都记在这里：

  • 第一次：只读接口字段 is_stop_register=0 就断言「注册没关」——方向碰巧对了，但论证是空的，接口字段本来就可能和前端行为不一致。
  • 第二次：改用浏览器打开注册页看渲染，看到「已暂停注册」就推翻重写——这次是真错了。因为那次打开用的地址是 #/login?type=reg&affcode=，affcode 后面是空的，正好命中「没带邀请码」这个条件。

教训是：既不能只读接口，也不能只看一次页面渲染——得看清楚那个页面是在什么输入条件下渲染出来的。 带参数的页面，参数就是输入条件的一部分；用空参数测出来的结果，只能代表空参数那一种情况。真正能定论的是渲染条件本身。

怎么确认 taffy.cloud 和 tf520.top 是同一家

这不是推测，是逐字节比对出来的。把两个 API 的 guest 配置接口拉下来对比，api.taffy.cloud 和 api.tf520.top 返回的 JSON 完全相同，四项关键指纹一致：

  • 条款地址 tos_url 和应用地址 app_url 都指向 tf520.top
  • reCAPTCHA 站点密钥是同一个 6LfjFXwdAAAAAN5KWTPbGWViKSE0m6W91gIgYe8K
  • 邮箱白名单十个后缀逐字相同
  • 应用描述都是「按量付费，永不过期」

同一套后端、同一个验证码密钥，这是同一家在用两个域名，不是两家机场。

一个容易踩的坑：旧域名的 API 还活着

tf233.top 和 tf91.top 的首页虽然只剩 404，但它们的 api 子域仍在服役——api.tf233.top 和 api.tf91.top 返回的配置和现役域名一模一样。

这意味着：你手上的老订阅链接可能表面上还在正常拉节点，让你误以为旧域名还是有效入口。 但前台已经撤了，说明站方已经把它们当废弃域名处理，随时可能一起关掉。把 tf520.top 存进收藏夹，别指望旧链接。

顺带一提，get.apple-render.top 这个订阅下发域名的根路径会 302 跳到 developer.apple.com/cn ——域名起成这样、根路径跳 Apple 官网，是让订阅请求看起来更像正常流量的伪装做法。对你没影响，知道一下即可。

官方邀请短链没坏，是测法容易出错

hasucn.me 是官方用的邀请短链域名，格式是 /i/ 加邀请码。这个服务是正常工作的：

地址实测结果
hasucn.me 根路径404，18 字节纯文本 —— 这是正常设计，短链服务本来就不开放根目录
hasucn.me/i/ 加邀请码HTTP 200，返回一个完整 HTML 页面，网页标题是「永雏塔菲」

带邀请码的路径拿到的是一个 JS 跳转页：页面上写着「重定向跳转中...」，脚本里把目标域名用字符串拼接做了混淆（t''''f''''52''''0.top 再把 '''' 替换掉），然后取出 /i/ 后面那段邀请码，拼成正式注册地址跳过去。跳转靠浏览器执行 JS 完成，不是 HTTP 302——用命令行工具抓，拿不到跳转、只能拿到这段 HTML，很容易误判成「短链服务挂了」。

这段脚本还是本文域名换代那一节最硬的证据：它里面带着三条 alert 提示，原样写着 tafei.top 弃用、tf233.top 弃用、tf91.top 弃用，最终指向 tf520.top。站方自己把换代链写在了脚本里。

注册链接的正确格式

网上流传的这种写法是无效的：

  • ❌ tf520.top/#/register?code=邀请码 —— 面板没有 #/register 这个路由，打开会被重写成 #/login，?code= 参数被整个丢弃，邀请码根本传不进去
  • ✅ tf520.top/#/login?type=reg&affcode=邀请码 —— 官方自己的短链跳转脚本用的就是这个格式，实测参数完整保留

这个区别现在很要命：用错格式 → 邀请码丢失 → 页面判定你「没带邀请码」→ 显示「已暂停注册」→ 你以为这家关站了。很多人所谓的「注册不了」，其实是链接格式用错了。

站方的域名换代节奏，是本文认为最该让读者知道的风险信号。RDAP 查到的注册时间：

域名注册时间现状
taffy.cloud2023-06-15现役并行主域（挂 CF 盾）

把中间两行摆一起：tf91.top 注册于 2025 年 4 月底，tf520.top 注册于 2025 年 8 月初，中间只隔了约三个月。 第二代域名的服役期短得只有一个季度。

这说明什么，得说得克制：频繁换域名通常反映持续的抗封压力，这在 2026 年的行业环境下并不罕见；但对用户的直接后果是实打实的——很容易失联，你收藏的地址过几个月就可能变成一行 404。这也解释了为什么 SERP 上一堆「Taffy Cloud 最新官网地址」的第三方页面在抢流量，以及为什么那些页面上的信息一个比一个旧。

还有个细节：tf520.top 的注册记录在 2026-08-06 刚更新过（续费），域名续着，说明短期内没有放弃这个入口的打算。

顺便证伪一条流传的说法

「taffy.cloud 已失效」——不成立。它返回 403 是 Cloudflare 的人机验证（响应头里明写 cf-mitigated: challenge），过盾就能进，它的 API 子域也一直正常。把 CF 盾当成域名失效，是这类页面最常见的误判。

它不卖月付套餐，只有一种玩法：充余额，然后按实际用掉的流量扣费，余额和流量都不过期。

每 GB 单价：本站没取到，所以不写

本文不给每 GB 单价数字，因为本站这次没有测到。 原因是账户在未充值激活的状态下，面板的节点接口返回的是空数组，单价要充值激活后才能在面板内看到。没充值，就不编。

官方帮助文档里用 0.2 元/GB 举过例子，说明扣费怎么算，但那是文档里的示例数字，不是价目表，本文不拿它当单价。网上第三方页面列的那些单价档位，本站无法独立核实，一个数都不转述——未经核实的价格一旦写出来，读者就会当参考价用，宁可缺着。

⚠️ 顺带说明一个可能误导人的东西：这家的套餐接口是匿名可读的，任何人拉一下都能看到五个叫「用户 A 组」到「用户 E 组」的条目，价格从 99 元、999 元一直到月付 2000 元、20000 元。这些不是零售价——数值不合常理、官网页面也不展示，判断是内部分组或历史遗留。看到有页面拿这些数字当它的套餐价，那是抓接口抓岔了。

单价不公开这件事本身也是个信息：本站写过的按量付费机场里，魔戒和 STC 的每 GB 单价都是购买前公开可查的，而这家要先掏钱才看得到。这算不上大问题，但它确实抬高了比价成本。

动态计费：晚高峰贵、深夜便宜

官方文档里还提到一类动态计费节点：名称后缀会标出来，不给固定单价，要展开节点点开才能看到当前价格。官方给的理由是平衡节点成本、削峰填谷。说人话就是不同时段价格不一样，大流量的活儿挪到低谷时段更划算。

两个容易吃亏的机制：账户休眠与每日限额

这两条官方文档里都写了，但都不在显眼位置，而它们恰好卡在这家最主要的使用场景上。

账户两个月不用会被休眠

官方文档白纸黑字：账户长时间未产生过流量记录（一般为 2 个月），会被系统判定为闲置账户并主动休眠。休眠状态下，你的订阅无法连接任何节点，所有节点都显示 Timeout。

解除办法是：登录官网 → 主页点「解除休眠状态」→ 等 2 到 3 分钟 → 恢复。官方还建议，实在用得少，就每个月花三分钟连上去看个视频，保持流量记录。

把这条和「余额永不过期」放一起看，问题就出来了：

  1. 你买它多半是因为「流量永不过期，适合当备用」；
  2. 但备用的定义就是平时不用——两个月一到，账户自动休眠；
  3. 等你主力机场挂了、急着切过来的时候，发现全部节点 timeout；
  4. 解除休眠必须登录官网——而这家的官网域名换过两代；
  5. 最坏的组合：主力挂了、备用休眠了、官网地址还过期了。

本站核实时用的账号，登录后看到的正是这个状态：面板中间一个灰框写着「您的账户已进入休眠状态」，节点列表和充值入口都被盖住。冲着"备用"买它的人，务必设个月度提醒连一次。 光有余额不够，得有流量记录。

每日消费限额：好功能，但官方自己说别太当真

按量付费最怕的事故是"忘关代理挂着下 Steam"，一觉醒来余额没了。这家给了个对症的功能：每日消费限额。超过当日设定金额后，系统把你限速到 5Mbps，每天 0 点重新计算，新用户没设置的话会被自动分配一个默认值（默认 2 元）。

功能是好功能，但官方在文档里连着两处写了同一句免责：如果流量消耗速度过快，比如 5G 或高速宽带下载，因为用户与节点之间存在时间同步差，他们无法准确限制，请不要过度依赖，限制失败产生的损失不负责。

这话说得实在，但你得听懂它的含义：限额是软刹车，不是保险丝。 真正的防线还是自己的分流规则——别开全局、别让下载器走代理。

常见问题

Taffy Cloud 和永雏塔菲的魔法卷轴是两家机场吗？

是同一家。 Taffy Cloud 是英文品牌名，「永雏塔菲的魔法卷轴」是面板上挂的中文名，帮助文档叫《魔法卷轴使用说明书》。你在不同导航站看到这几个名字被分别收录，是同一家被写了好几遍。「塔菲云」这个叫法几乎没人用。

它真的暂停注册了吗？

没有，注册一直开着，但必须带邀请码。 造成误会的是页面设计：不带邀请码打开注册页，显示的不是「请输入邀请码」，而是一整张「本站目前已暂停注册，只维护现有用户」的卡片，还引导去友站，页面上一个输入框都不渲染。但前端源码里这段提示的条件写着「强制邀请码开启且当前没有邀请码，或注册开关被关闭」，而实测强制邀请码=1、注册停用开关=0——触发它的是「没带邀请码」。带上有效邀请码打开同一个地址，注册表单正常出现。 另外注意链接格式：#/register?code= 是无效写法，参数会被丢弃，也会导致你看到那张卡片。

它真的是原来的 MoFast 魔法云吗？

是接手方，不是原班人马改名。 MoFast 2023 年 6 月 16 日公告转让，Taffy Cloud 作为买家接管域名和用户数据；taffy.cloud 域名注册于 6 月 15 日，比公告早一天，时间线对得上。当时承诺老账号可直接登录、数据全保留，但有评测站记录自己的账号一天后就被提示不存在、余额消失（单一来源，本站无法复现）。买它的账要算在新东家头上，MoFast 时期的口碑不能直接继承。 另外「开业可追溯到 2021 年」说的是 MoFast，不是它。

官网是哪个？旧域名还能用吗？

现役官网是 tf520.top，网页标题就是「永雏塔菲的魔法卷轴」。并行主域 taffy.cloud 挂着 Cloudflare 盾，会先显示「Just a moment」，过盾进的是同一套系统——两者同属一家已实测确认（两个 API 配置逐字节相同、reCAPTCHA 密钥同一个）。旧域名 tf233.top / tf91.top 的首页已经是一行 404，别再用。 有个坑：这两个旧域名的 api 子域还活着，老订阅链接可能看起来还能拉节点，但那不代表旧域名还是有效入口，随时可能一起停。

多少钱？每 GB 单价多少？

纯余额制按量付费，不卖月付套餐，充值档位 ¥5 / ¥10 / ¥20 / ¥50 / ¥100，也能自定义，5 元起充。付款走 EPay，两个通道手续费 7% 和 2.5%，选低的。每日消费限额默认 2 元、超额限速 5Mbps、可调。每 GB 单价本文不给数字——账户未充值激活时面板节点接口返回空数组，单价要充值后才可见，本站没充就不编；官方文档里的 0.2 元/GB 是讲扣费怎么算的示例，不是价目表；第三方页面列的那些单价本站无法核实，一个数都不转述。注意官方明示不退款。

我的节点全都 timeout 了，怎么回事？

三种常见原因，按这个顺序排查：① 账户被休眠了——两个月没产生流量记录就会自动休眠，登录官网点「解除休眠状态」等 2–3 分钟；② 客户端太老不支持 VLESS——导入订阅只能看到几个节点、直连节点全不可用，升级客户端即可；③ 订阅配置过期，更新订阅。面板置顶公告对后两种都有说明。
