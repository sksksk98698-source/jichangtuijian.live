STC机场是什么?

STC(STC-SERVER)是一家成立于 2020 年之前、运营至今 6 年上下的机场——这个行业大量新店开半年就跑路,它熬过了好几轮行业洗牌,多家评测站留有它跨年度的历史测速存档,limbo 跑路预警名单上查无它的记录。「耐活 + 无案底」,这两条在机场圈就是最实在的信任背书。

它走低调路线:不打广告、不搞花哨营销,靠老用户口碑活着。产品是标准机场形态——订阅链接导入 Clash 等客户端,协议 SSR + Vmess,评测口径老板在墙外(香港)。

核心特色:按量付费——但先算清这笔账

STC 最常被点名的原因就是按量付费,机场圈稀缺:

  • ¥0.8 / GB,8 元(10G)起充
  • 不用不扣——没有月底清零,闲置期零成本
  • ⚠️ 但不是永久有效:有评测口径按量流量有效期为 365 天,以官网当前说明为准

它适合谁,一道算术题就说清了。 基础月付 ¥38/100G,折合 ¥0.38/G;按量 ¥0.8/G 是它的两倍多。两边的平衡点:38 ÷ 0.8 ≈ 47G/月:

  • 月用量低于 47G、或用量忽高忽低(这个月 3G 下个月 40G)→ 按量完胜:用多少付多少,不用白交订阅费;
  • 月用量稳定超过 47G → 老老实实转月付基础版,按量反而亏;
  • 不确定自己是哪种? 先充 8 块钱按量用一个月,后台看用量,数字会告诉你答案——这也是全机场圈试错成本最低的验证方式。

一句话:按量付费卖的是「灵活」,不是「便宜」。 网上把 STC 按量吹成「高性价比」的,都没帮你算这笔账。

⚠️ 官网为什么打不开：本站的完整探测过程

结论先说：源站连不上了。 下面是 2026-09-20 的逐步探测，也记录了本站自己走过的两个弯路。

第一步，看 DNS：老域在国内被污染。 用国内 DNS 查 www2.gardenparty.me 拿到 8.7.198.46、查 www1 拿到 93.46.8.90——都是众所周知的污染地址；而用境外 DNS 查，四个子域全都解析到同一对正常的 Cloudflare IP。这一步只能说明这个域在国内被墙，还不能说明站点死活。

第二步，挂代理去开：被 Cloudflare 拦了。 本站用代理打开 1p2c.gardenparty.me，页面直接是 「Sorry, you have been blocked」。这和被墙是反着来的——被墙要挂代理才能开，拦代理 IP 则要关掉代理。到这一步为止，本站仍然无法判断源站是不是活着，因为拦截页是 Cloudflare 发的，跟后面有没有服务器无关。

第三步（关键），借第三方服务从墙外看。 这一步本站一开始做错了：用 r.jina.ai 和 allorigins 的 /raw 端点，都拿到了完整的首页和注册表单，于是判断「站点是活的，只是你进不去」。

但那是缓存。 换成 allorigins 的实时端点 /get、以及另一个独立服务 codetabs 再测，结果全变了：

七次实时探测，六次返回 Cloudflare 522。 522 的意思很明确：Cloudflare 的边缘节点是活的（所以它能给你吐错误页），但它连不上后面的源站服务器。

这里有个值得记住的教训：跑路或停服的站，搜索引擎快照和各种抓取服务还会继续吐出它的旧页面很久，看起来像"还活着"。要判断死活，必须找明确标注实时、不走缓存的探测方式——同一个服务的两个端点，结论可能完全相反。

⚠️ 另一个域 stcserver-cloud.com 也不要用。 搜索结果里会出现它，标题写着「STC-SPADES」，证书 2026-09-17 还在签发、国内 DNS 解析也干净——但打开是 Cloudflare 的 Error 1016「Origin DNS error」，连源站域名都解析不出来。证书还在自动续签只说明域名还挂在 Cloudflare 上，不代表后面还有服务器，这是同一个陷阱的另一种形态。

现在该怎么办：已经买了的，等它恢复，别再充值；还没买的，直接看文末的替代，别在这上面耗时间。本站无法确认这是临时故障还是永久停运，会持续跟进。

节点与线路:亚洲为主,稳字当头

  • 覆盖:香港、日本、新加坡、美国、台湾为主力——亚洲近距离节点,日常延迟低;
  • 架构:低档 BGP 中转、高档 BGP+IPLC 混合,整体是「稳字当头」而不是堆峰值速率;
  • 已知毛病(评测口径一致):总有个别节点不在线——遇到就换节点,这是它多年的老习惯了,不是跑路信号;
  • 硬限制:不支持 IPv6;不支持 Surge / Surfboard 客户端;
  • ⚠️ 内容过滤要知情:官方明示屏蔽部分媒体类网站(评测原文「屏蔽轮媒」)。这说明它后台有内容过滤策略——对多数人无感,但对内容自由/隐私敏感的用户,这是个该知道再决定的信号。

协议这块要单独敲黑板:只有 SSR + Vmess。SSR 是快十年前的协议,Vmess 也算不上新,没有 Trojan/Hysteria2/VLESS+Reality 这些新一代抗封锁协议。平时走中转/专线无所谓,可一到严打敏感期,老协议 + 纯 BGP 中转的低档套餐,容错明显弱于多协议机场——2026 年这一轮封锁升级下,这不是吹毛求疵,是真实差距。

ChatGPT 与流媒体:一个能打,一个拉胯

  • ChatGPT / OpenAI:✅ 可用,走日本/台湾节点即可,多方口径一致;
  • 流媒体(Netflix/Disney+ 等):⚠️ 解锁一般,多家评测口径一致「解锁不好」——它不是原生 IP 解锁型机场。

定位记清楚:STC 是「稳定上网 + AI 工具」型,不是「追剧」型。 核心需求是看各区流媒体的,直接绕行,别买了失望。

Clash 设置

标准机场,导订阅就行:

  1. 官网后台复制订阅链接;
  2. Clash Verge / 手机 Clash 客户端 → Profiles → 导入订阅并更新;
  3. 代理页做延迟测试,主用香港/日本节点;用 ChatGPT 切日本/台湾;
  4. 开系统代理 / TUN 模式;
  5. 个别节点不在线是它的老毛病,换节点即可;节点变动记得更新订阅;
  6. 记住硬限制:Surge/Surfboard 不支持,IPv6 没有。

STC机场靠谱吗?

把证据摆开:

  • 正面:2020 年前开业、运营 6 年上下;limbo 跑路预警名单查无记录;多家评测站跨年度持续收录测速;老板在墙外的评测口径——这套履历在机场圈属于第一梯队的干净;
  • 中性:低调不营销,信息更新慢,官网域名(gardenparty.me)不算广为人知——第一次买之前认准官网、防钓鱼站的方法看这篇;
  • 提醒:老牌 ≠ 保险箱,行业属性摆在那。好在它的按量付费天然就是风险对冲:8 块钱试水、按需补充、绝不囤大额——用它,就用它自己发明的方式管住风险。

适合谁?不适合谁?

👍 适合:用量不规律/低频翻墙的人(按量是为你发明的);要一条老牌无案底的备用线的人;主用 ChatGPT/AI 工具 + 日常上网的人。

👎 不适合:重度追剧党(解锁一般);性价比党(高档 ¥0.88+/G 偏贵);要新协议、要 IPv6、要 Surge 的技术流;以及介意服务商做内容过滤的人。

常见问题(FAQ)

STC机场是按量付费还是月付?

两种都有:按量 ¥0.8/G、8 元(10G)起充、不用不扣;月付 ¥38–108/100G 四档。低频用按量,月用量稳定超 47G 转月付。

按量付费的流量会过期吗?

不会月底清零,但不是永久——有评测口径有效期 365 天,以官网说明为准。别一次囤太多。

能用 ChatGPT 吗?

能,日本/台湾节点即可。

能看 Netflix 吗?

能连,但解锁一般,多家评测口径一致。重度追剧选原生 IP 解锁型机场。

支持哪些客户端?

Clash 系、v2rayN、小火箭;不支持 Surge/Surfboard;协议 SSR+Vmess,没有新协议,敏感期容错压低预期。

STC 会跑路吗?

无案底、老牌、多年存活,风险相对低;但仍按机场圈通则:小额充值、保留备用线。它的按量模式本身就是最好的对冲。
