怎么挑代理软件

  1. 01

    先选机场，再挑软件

    客户端只是壳，速度和稳定性由机场节点决定。先确认机场提供什么订阅格式（Clash 订阅/通用订阅），再选对应支持的客户端。

  2. 02

    认准开源与官方下载渠道

    主流客户端全部免费开源，只从 GitHub 官方仓库或官网下载。任何收费出售、二次打包的「破解版/纯净版」安装包都可能被植入后门。

  3. 03

    协议要与机场匹配

    老内核不认 Hysteria2 等新协议。机场主打新协议的，客户端选 mihomo / sing-box 这类持续维护的新内核，别用停更的旧版。

  4. 04

    iOS 用户提前备外区账号

    国区 App Store 没有翻墙客户端，Shadowrocket 等需要外区 Apple ID 购买；别去淘宝买共享成品号，账号风险高。

Clash 系客户端

免费开源

Clash for Windows 在 2023 年 11 月停更删库后，主流替代是三个基于 mihomo（Clash.Meta）内核的客户端：Clash Verge Rev、FlClash、Mihomo Party。三者协议支持能力一致，VLESS、Hysteria2、AnyTLS 都认，订阅在它们之间完全通用，差别只在界面、平台覆盖和资源占用——从 Clash for Windows 迁过来选 Clash Verge Rev（习惯最接近），要电脑手机一套选 FlClash（跨平台最全），喜欢新界面选 Mihomo Party。比选哪个更要紧的是从哪下：搜索结果里有大量以「备份下载地址」「中文官网」为名的第三方站，而代理客户端掌握你的全部流量，认准项目自己的 GitHub 仓库是底线。

迷雾通 Geph

免费

Outline

免费开源·需自备VPS

Outline 是 Google 母公司 Alphabet 旗下 Jigsaw 开发的开源、免费自建 VPN 工具，不是机场——它用 Outline Manager 在你自己的 VPS 上一键搭 Shadowsocks，再用 Outline 客户端凭「访问密钥」连接。适合有动手能力、想自己掌控的人；只想稳定翻墙、不想碰服务器的人，买机场更省心。

WireGuard

免费开源

开源极简的现代 VPN 协议（代码约 4000 行、已并入 Linux 内核），快、省电、配置简单；但无流量混淆、UDP 特征会被 GFW 识别，在中国大陆裸用翻墙不可靠。正确用途是自建 VPN 远程回家、异地组网和商业 VPN 底层协议；翻墙请用抗审查协议的机场。

代理软件常见问题

机场客户端是免费的吗？要花钱吗？

桌面和安卓的主流客户端（Clash Verge Rev、v2rayN、v2rayNG 等）全部免费开源；iOS 是例外，Shadowrocket 约 US$2.99 买断。钱应该花在机场订阅上，遇到收费出售免费软件的一律绕开。

Clash 不是删库停更了吗，还能用吗？

原版 Clash 内核 2023 年末停止维护，但社区由 mihomo（Clash Meta）内核接棒，Clash Verge Rev 等客户端持续更新，机场的 Clash 订阅生态不受影响，可以正常使用。

iOS 怎么装机场客户端？

国区 App Store 无法下载，需要注册或购买外区 Apple ID，再购买 Shadowrocket 等客户端。部分机场提供 TestFlight 测试版客户端，但名额和稳定性都没保证。

代理软件和一键 VPN 有什么区别？

代理软件本身不提供节点，需要搭配机场订阅使用，软件开源、节点可自选可更换；一键 VPN 是软件＋节点一体的闭源服务，质量与安全完全取决于服务商，不可控风险更高。

用哪个客户端速度最快？

速度主要取决于机场线路质量，客户端之间的性能差异很小。选维护活跃、支持你机场订阅格式和协议的客户端即可，不必为「跑分」纠结。
