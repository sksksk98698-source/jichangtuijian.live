糖果云怎么样？红杏云的专线分站，送EMBY但流量扣得有点猛

更新于 2026-06-27·主笔测评：林浩（资深网络工程师）·多地机房实测

30 秒结论：糖果云（Candytally）是 2025 年新开的专线机场，是知名机场「红杏云」的高端分站（红杏云把自己的专线套餐拨给了它独立经营）。IEPL 专线、Trojan 协议、家宽节点，解锁 Netflix/Disney+/ChatGPT，还赠送 EMBY 影视库（亮点），不在跑路名单里，靠红杏云背书、靠谱度尚可。但要诚实说几个短板：① 有用户实测反馈「扣流量偏多」（称下载 1GB 扣了 3GB）、家宽/解锁节点容易跳 IP 封号、客服响应慢；② 电信用户体验较差（更适合移动/联通）；③ 近期出过冷门节点失效（已恢复）。结论：作为红杏云专线分站、要 EMBY 和家宽节点的人可以月付试，但建议买 200G 以上档（留足流量余量）、电信用户慎选、只月付。

⚠️ 先消歧：糖果云机场 ≠ 同名的糖果云 IDC（卖 VPS 的）

买之前先认准，有两家「糖果云」别搞混（多家评测都专门提醒）：

  • 糖果云机场 / Candytally（本文）：红杏云的分站，卖机场订阅（翻墙节点）
  • 糖果云 IDC：另一家同名服务商，卖的是 VPS 服务器——不是机场，别买错

认准糖果云机场的官方域名（candytally2.com 等，完整清单见下一节），别在卖 VPS 的同名站下单。

糖果云官网入口：一共十九个域名，但只有六个能直接注册

这家的域名多得离谱，而且分三层——搞不清会白绕两圈。本站 2026-08-25 把它们逐个打开测过，结论先放这里。

这六个是面板本体，打开就是登录/注册页，本站实测国内不挂代理也能打开：

② 官方公告里那八个「永久域名」——能打开，但要多绕一圈

糖果云后台的《官方域名公告》列了这八个：

candytally.com、candytally.vip、candytally.net、candytally.cc、candytally.co、candytally.love、candytally.one、candytally.us、candytally.club

它们确实是官方的、也确实能打开，但打开后你看到的不是注册页，而是一个「正在检测…」的中转页面，几秒后把你转到另一个地址；转过去之后落在官网首页，你还得自己再点一次「登录/注册」。

能用，就是多绕两步。 手上有上面第一组地址的话，直接用第一组更省事。

③ 老域名 candytally.xyz 已经打不开了

本站早前版本推荐的 candytally.xyz，现在已经无法访问——不是被墙那种「挂代理就能开」，是挂了代理也打不开：查它的地址会拿到一个明显不对的结果（几个不同的公共 DNS 给出的答案互不相同，且都是无效地址）。

如果你收藏的是这个地址，请换掉。 域名注册记录本身还没到期，但它已经不能作为入口用了。

一句话：收藏 candytally2.com 和 candytally.cyou，两个都打不开时再去试 candytally.com 那一组。官方邮箱 Candytallycloud@gmail.com、官方 Telegram 机器人 @Candytallyvip_bot 可以作为最后的找回途径。

糖果云是谁家的？红杏云的高端专线分站

搞清身世有助于判断它的可靠性：

  • 糖果云是「红杏云」2025 年开的高端分站：早期红杏云有「公网隧道中转 + 专线」两类套餐，后来红杏云撤掉了自己的专线套餐，把专线资源拨给糖果云独立经营——所以糖果云专做专线
  • 背书来源：背靠 红杏云（运营有年头的知名机场），比纯野生新机场靠谱度高一些。评测定性「作为主打高端专线的分站，靠谱程度应该还行」
  • 但仍是「新机场」：2025 年才独立经营，月付保平安这条照样适用

⚠️ 糖果云的几个真实短板（用户实测，必看）

为了不让你踩坑，把用户实测反馈的问题如实列出（这也是搜「糖果云不行了 / 怎么样」该看的）：

1. 扣流量偏多。 有用户实测反馈：「下载 1GB 的文件，扣了 3GB 流量」，建议「最好 200GB 起订，不然不够用」。——⚠️ 这点很重要：如果属实，说明它的流量结算可能偏狠，所以别买小流量档（100G 可能不经用），要留足余量。

2. 家宽/解锁节点容易封号。 有用户用糖果云节点养 TikTok/YouTube/Instagram 账号，**多次出现「使用几天后账号被封」**的情况。说明：机场的家宽/解锁 IP 是共享的，用来养社交账号（尤其 FB 系）风险高——这不是糖果云独有的问题（所有机场共享 IP 养号都有风险），但你要知道：别拿它当「养号专用干净 IP」用，重要社交账号注册/运营建议用独享方案。

3. 客服响应慢、不退款。 有用户投诉客服「三句话回复了 3 天」「工单被关了还不给退款」。——它不支持退款，所以务必先月付小额试，别上来大额。

4. 电信用户体验较差。 评测明确：糖果云适合移动、联通用户，电信用户体验稍差。电信用户要么慎选，要么先月付实测你本地电信线路行不行。

糖果云"不行了"？——近期节点波动，非跑路

长尾「糖果云不行了」，澄清：

  • 不在跑路名单（limbo 跑路库等均无收录），红杏云分站，目前正常运营
  • 近期出过冷门节点失效：官方公告称「已恢复大部分冷门节点，线路持续优化中」——属节点波动，不是跑路
  • 遇到节点无法用/不显示：按官方指引，删除旧订阅→重新导入→优先用官方客户端；它近期也在切新协议，旧订阅要刷新
