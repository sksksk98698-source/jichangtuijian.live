DuangCloud跑路时间线(事实梳理)

把这件事按时间捋清楚,你就能看懂「跑路 / 复活 / 被收购」到底怎么回事:

  • 跑路前:DuangCloud 是运营数年的老牌机场,主打华为 BGP / IEPL 内网专线、无倍率、不限速、能看 Netflix,口碑不错,很多人放心地按年续费——这也正是后来损失惨重的原因。
  • 2024-08 下旬:用户反馈官网失效、节点暂能用但无法更新,在线客服与工单无人处理——事后看是预兆。
  • 2024-09-01 前后:节点全线超时、官网无法访问,第一次大面积崩盘。
  • 2024-10 中旬:官网一度悄悄恢复、套餐还在,看似「活过来了」。⚠️ 这个「假复活」很关键——它说明「Duang 又能用了 / 复活了」并不等于安全。
  • 2024-10 下旬:节点再次大面积不可用、官网再失联,持续至今——这一次被多个名单正式坐实跑路。
  • 发酵期:官方长时间不出面;TG 群陷入混乱,出现用 Duang 官方同款头像、建「DuangCloud Channel」的人,喊「原频道丢失 / 有安全问题,紧急迁移」,引导去一个同名新机场并发五折券。
  • 关联线索:DuangCloud 与另一家机场 Wallless 疑为同一老板——有用户「是 Duang 用户却收到 Wallless 邮件」,两家订阅同一 IP、套餐定价雷同,且两家跑路公告几乎是同一模板换个名字。

所以那些长尾疑问的答案:

  • 「DuangCloud 复活 / 被收购了吗?」→ 没有可信的「复活」。所谓改名 LMout、或各种「紧急迁移」,要么源头自己都说无法核实,要么是借跑路拉新,不是原服务的延续。
  • 「DuangCloud 不能用了?」→ 对,2024 年下半年起就名存实亡,且不会真正回来;就算某个「duangcloud」域名一时能打开,也别再往里充钱。

为什么说"迁移/LMout/复活"基本都别信?

跑路机场最危险的不是跑路本身,而是跑路后的二次收割。DuangCloud 这一出,几乎集齐了所有套路:

  1. 冒名头像 + 假频道(套路:假官网 / 同名仿冒):有人用官方同款头像建「DuangCloud Channel」,专门骗你去他的机场。跑路混乱期,官方频道真假极难辨。
  2. 「紧急安全问题,请迁移」话术:以「原站有安全漏洞 / 频道丢失」制造紧迫感,逼你赶紧去「新站」下单——这是杀猪盘式的紧迫感营造。
  3. 「老板被抓、原团队改名」叙事(LMout)(套路:换皮重生):自称原班人马改名继续,但不迁移数据、要你重新付费。⚠️ 最值得警惕的一点:几乎一模一样的「老板被抓 → 电脑手机被扣 → 原技术团队另起新站 → 五折迁移」剧本,在 Wallless 身上又上演了一遍,连公告措辞都雷同。当同一套「被抓 + 迁移」故事被两家机场复用,它更像是收割模板,而非真实案情——本站无法独立证实,把它当风险信号看,而不是当事实信。
  4. 同老板多盘子(Wallless):一个老板疑似开两家,「碎一个还有一个挣钱」——这种结构下,你很难知道钱进了谁的口袋。

结论:无论「迁移 / 复活 / 收购」的故事讲得多真,对一个已跑路、且围绕它满是未证实「被抓」传闻的品牌,正确做法是清零止损、彻底换家,而不是跟着「新站」再交一次钱。

⚠️ 特别提醒:小心还在推DuangCloud的"教程站"

这是搜「DuangCloud 官网 / 注册 / 优惠码」时最大的坑:至今仍有不少带返利(aff)的「机场教程站」挂着 DuangCloud 的「注册教程 + 优惠码 + 邀请码」在推广,页面看起来正规,还信誓旦旦说「DuangCloud 跑路了吗?答:肯定没有,一直稳定运营」。

真相:这些站要么是没更新的过时内容,要么是为了 aff 返利揣着明白装糊涂。DuangCloud 早已跑路,任何现在引导你去 DuangCloud 注册、充值、用优惠码的页面,都不要相信——你充进去的钱大概率有去无回。认跑路名单(GFWOFF / limbo / PigchaVPN)和多方社区反馈,不认单方面的「教程站」说辞。

  2. 不要跟迁移:不要去 LMout 或任何自称「Duang 迁移 / 新站 / 复活」的地方重新付费。

  4. 清理客户端:删除 DuangCloud 旧订阅和节点,别让客户端继续拉一个失控的订阅地址。

靠谱替代:选不玩失踪的

DuangCloud 的教训是「老牌也会跑,且跑得悄无声息、还留下一地冒名迁移」。选替代就认运营透明、出事会公告、不搞神秘迁移的:

常见问题(FAQ)

DuangCloud跑路了吗?

是的。2024 年下半年(9 月初首崩、10 月中旬短暂恢复、10 月底再崩)起原服务全线中断、官网失联,已被 GFWOFF、limbo、PigchaVPN 等多个跑路名单坐实。它不会真正恢复,请换家。

DuangCloud复活/被收购了吗?

没有可信的复活。所谓改名 LMout、或各种「紧急迁移」,源头自己都说无法核实,更像借跑路拉新,不是原服务延续。即便某个「duangcloud」域名一时能打开,也别去重新付费。

DuangCloud改名LMout是真的吗?

LMout 自称 DuangCloud 原团队改名,但不迁移用户数据、需重新下单,且这一说法无法核实。即便属实,一个刚跑路完的团队也不值得再信一次;建议另选运营透明的机场。

DuangCloud和Wallless什么关系?

两家疑为同一老板:有用户串号(Duang 用户收到 Wallless 邮件)、订阅同 IP、套餐定价雷同,连跑路公告都像同一模板。一个老板疑似开两个盘子,跑路时一起出问题——这也是「迁移」剧本两家通用的原因。

听说DuangCloud老板被抓了,是真的吗?

「老板被抓、电脑手机被扣」目前只是未经证实的传闻,且这套说辞主要来自要你「迁移到新站」的一方、还被原样套用在 Wallless 上,本站不持立场、不当事实背书。无论真假,对你的建议都一样:钱基本要不回,做好改密码、清订阅,立即换家。
