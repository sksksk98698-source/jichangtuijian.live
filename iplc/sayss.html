SaySS机场怎么样：入门档没月付，半年付比买两次季付还贵

更新于 2026-08-25·主笔测评：林浩（资深网络工程师）·多地机房实测

30 秒结论：SaySS 是一家 2023 年 10 月起运营的 IEPL 专线机场，全线只跑 Shadowsocks 一种协议，不限设备数，套餐页标称 2000Mbps。它有两个别家少见的功能：IP 白名单（只允许你指定的 IP 访问订阅链接）和订阅日志（能看到订阅被谁访问过）。价格得把三档 × 六个周期逐个点开才算得清，算完发现两个坑：① 入门档 Basic 压根没有月付，最低季付 ¥100，而 Standard 月付才 ¥65、流量还是它的两倍——Basic 连买三年都比 Standard 季付贵，这档不该选；② Standard 和 Enterprise 的半年付是负优惠，买两次季付比买一次半年付便宜（¥292 vs ¥295、¥816 vs ¥826）。想试水的正确买法是 Standard 月付 ¥65，不是那个看起来最便宜的 Basic。

二、坑一：入门档没有月付，而它本来就不该买

把上面第二张表竖着看一眼就会发现——Basic 这一整行，没有一个数字能打得过 Standard。

先说最直接的：Basic 没有月付选项。别的两档都能月付，唯独最便宜的入门档不行，最低就是季付 ¥100，一次交三个月。想小额试水的人，在这一档面前直接被挡住。

而如果你退一步去看 Standard：

Basic 季付Standard 季付
价格¥100¥146
流量150 G / 月300 G / 月
每 GB¥0.222¥0.162

多花 46 块，流量翻倍，每 GB 单价还降了 27%。

更极端的对比是这个：Basic 买三年（¥900，¥0.167/GB），单价仍然比 Standard 季付（¥146，¥0.162/GB）贵。

也就是说：Basic 在任何周期上都不是划算选择。 它唯一的优势是「季付总价 ¥100 比 ¥146 低」——你省下的是一次性支出，不是钱本身。

如果你只是想试试这家好不好用，别买 Basic 季付，买 Standard 月付 ¥65 ——比 Basic 季付少掏 35 块，只锁一个月，流量还多一倍。

三、坑二：半年付比买两次季付还贵

这一条更隐蔽，因为它反直觉——周期越长应该越便宜，这是所有机场的默认规则。SaySS 有两档不是。

套餐季付 × 2半年付差额
Basic¥200¥190半年付省 ¥10 ✅
Standard¥292¥295半年付贵 ¥3 ❌
Enterprise¥816¥826半年付贵 ¥10 ❌

Standard 和 Enterprise 的半年付，都比连买两次季付更贵。

差价不算大（¥3 和 ¥10），但方向是错的——你多锁了三个月的钱，却多付了钱。这两档的半年付按钮，直接跳过就行。

（只有 Basic 的半年付是正常打折的。这也侧面说明这不是刻意设计的陷阱，更像是三档价格分别定、没有横向对齐过。但对你来说，结果一样。）

所以这家的周期选择规则很简单：要么按月/按季短买，要么直接跳到年付以上——半年付这一档，在 Standard 和 Enterprise 上没有存在意义。

四、那两个「不限时」大流量包，贵 4.67 倍

SaySS 有两款一次性套餐，卖点是「流量用完为止，无时间限制」——不按月清零，慢慢用。

听起来很划算，直到你把它和月付放在一起：

流量价格
Enterprise 月付1064 G（当月用完清零）¥150
Count_Standard 一次性1064 G（不限时）¥700

同样 1064GB，一个 ¥150，一个 ¥700 —— 贵 4.67 倍。

多出来的 ¥550，买的只有一件事：流量不按月清零。

这笔账该怎么算，取决于你的用法：

  • 每月都能用掉大部分流量的人：一次性包毫无意义，¥150 的月付完胜；
  • 一年只出差几次、平时用不上的人：一次性包是合理的——你要是买月付，没用完的流量每月都在蒸发，¥700 分摊到两三年也就每月二十几块。

判断标准只有一个：算算你一个月实际用多少 GB。如果超过 300G，别碰一次性包；如果一个月只用几十 G，那 ¥700 买 1TB 慢慢花确实比每月扔掉 900G 强。

五、它两个别家少见的功能

这是 SaySS 比较有意思的地方，后台侧边栏里有两个大多数机场没有的菜单。

IP 白名单：防订阅被盗用

「只有白名单中的 IP 可以访问您的订阅链接」「添加常用网络后，异常 IP 访问订阅会被拦截并记录」

可以把常用网络加成「家庭 IP」或「海外 IP」，加完之后别的 IP 拿着你的订阅链接也用不了。后台还有一块「被拦截的 IP 记录」，显示最近 30 天未通过验证的访问次数和独立 IP 数。

默认是关闭的（本站账号显示「已添加的 IP (0)」），要自己去开。

  • 好处：订阅链接是机场里最容易泄露的东西——发给朋友、存在网盘、被客户端同步走。开了白名单，泄露也不怕。
  • 代价：你换网络就可能被自己挡在外面。出差、换 WiFi、切 4G/5G，IP 一变订阅就更新不了，得先想办法回后台加 IP——而这时候你可能正没网。

建议：固定在家用的人可以开；经常换网络的人别开，或者只把家庭宽带加进去、留着移动网络不管。

订阅日志：看谁在用你的订阅

后台能看到订阅链接最近 7/30/90 天的访问次数、独立 IP 数、客户端类型分布、国家地区分布，以及每一条访问明细。

这个功能的实用价值是发现异常——如果你的订阅突然多出陌生地区的访问，那就是泄露了。搭配上面的白名单一起用，是这家在「订阅安全」上做得比同行细的地方。

六、官网入口：地址栏变成一串 IP 是正常的

这家的入口结构和大多数机场不同，第一次用会懵，这里说清楚。

官方入口是 www.sayss.net ——但它本身不是面板，而是一个标题就叫「线路检测」的中转页。你打开它，它会自动检测并把你送到当前可用的面板地址。

本站实测：打开 www.sayss.net，最终落在 118.193.36.230 这个裸 IP 面板上，浏览器地址栏会变成一串数字。

这是正常的，不是被劫持。 面板本身就部署在 IP 上，域名只负责把你导过去。

另外它还有两个域名在后台默默干活：数据接口走一个域、订阅链接走另一个域（你复制到的订阅地址不是 sayss.net 开头的，这也是正常的）。三个域名分工不同，任何一个出问题都会影响使用——本站已经把它们的到期日逐个记下来，会持续复核。

八、该不该选它

适合：

  • 想要 IEPL 专线、设备数不限（一家人 / 多设备共用）；
  • 在意订阅安全——IP 白名单和访问日志这两个功能，同价位机场基本没有；
  • 用 Shadowsocks 够用、不需要 Hysteria2/VLESS 这类新协议。

不适合：

  • 想先花十几块试水的人——这家最低门槛是 Standard 月付 ¥65（Basic 那个 ¥100 是季付，锁三个月）；
  • 需要多协议切换来对抗封锁的人（这家只有 SS 一种）；
  • 希望有明确退款兜底的人（本站未找到条款页）。

买法建议：

  1. 先 Standard 月付 ¥65 试一个月，别碰 Basic；
  2. 觉得好用就跳到年付（¥540，¥0.15/GB），别选半年付；
  3. 流量需求大且确定长期用，Enterprise 年付 ¥1450（¥0.114/GB）是这家单价最低的现实选项——三年付虽然更便宜，但没有任何机场值得押三年；
  4. 一个月用不到 300G 的人，再考虑那两款一次性包。

常见问题（FAQ）

SaySS 机场怎么样？ 2023 年 10 月起运营的 IEPL 专线机场，只跑 Shadowsocks，不限设备数，有 IP 白名单和订阅日志两个少见功能。价格中等（月付约 ¥0.14–0.22/GB）。要试就买 Standard 月付 ¥65，别买 Basic。

SaySS 官网入口是哪个？ www.sayss.net。它是「线路检测」页，会自动把你转到实际面板（本站实测落在裸 IP 118.193.36.230），地址栏变成 IP 是正常的。国内不挂代理能打开，邀请码会自动预填。

为什么 Basic 没有月付？ 这是它的定价设计，本站只能陈述事实：三档里唯独入门档没月付、最低季付 ¥100。而 Standard 月付 ¥65 更便宜、流量还翻倍——所以这个限制的实际效果，是把想小额试水的人推向 Standard。

半年付真的比季付贵？ 是的，Standard 和 Enterprise 两档如此：季付 ×2 分别是 ¥292 / ¥816，半年付却要 ¥295 / ¥826。买两次季付更便宜。（Basic 的半年付正常打折。）

IP 白名单要开吗？ 固定在家用可以开，能防订阅泄露；经常换网络的别开，IP 一变你自己也会被拦，得回后台加 IP。默认是关的。

支持什么协议？能打游戏吗？ 只有 Shadowsocks 一种。速度、游戏体验、解锁能力本站未实测——没买套餐，节点列表拿不到。

有优惠码吗？ 截至 2026-08-25 本站未发现可用优惠码，后台公告栏只有一条且停在 2026-04-24。
